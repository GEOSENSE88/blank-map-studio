# 백지도 스튜디오

세계지리 출제용 백지도 편집기. `dist` 폴더를 정적 웹 서버로 제공하면 실행됩니다. 외부 서비스 요청 없이 동봉한 지도 자료를 이용합니다.

## 주요 기능

- 지역·중심 경선 선택, 확대·이동, 화면 비율
- 국가별 음영·빗금과 자동/직접 기호, 드래그로 기호 이동
- 지점, 연결선, 강조 타원, 명조·고딕, 국경선·적도·경위선
- PNG 300/600 dpi와 SVG 다운로드, 편집 작업 JSON 저장/열기, 되돌리기

## 참고 자료

스타일 참고: 사용자 제공 2026년 6월 고3 1·2쪽, 2025년 11월 수능 3쪽, 2025년 9월 고2 2쪽. 흑백 바다, 회색 국가 음영, 점선 국경, 바깥쪽 기호와 연결선, 태평양 중심 지도 등을 참고했습니다. 원본 기출문제는 사이트에 포함하지 않았습니다.

지도: Natural Earth 1:50m admin_0_countries 및 land. https://www.naturalearthdata.com/about/terms-of-use/ (public domain). 모든 국가·영토 경계는 원자료에 따릅니다. 작은 섬의 상세도에는 1:50m 자료의 한계가 있습니다.

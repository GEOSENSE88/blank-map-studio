# 백지도 스튜디오

세계지리 출제용 백지도 편집기. `dist` 폴더를 정적 웹 서버로 제공하면 실행됩니다. 외부 서비스 요청 없이 동봉한 지도 자료를 이용합니다.

## 주요 기능

- 지역·중심 경선 선택, 확대·이동, 화면 비율
- 국가별 음영·빗금과 자동/직접 기호, 드래그로 기호 이동
- 지점, 연결선, 강조 타원, 명조·고딕, 국경선·적도·경위선
- PNG 300/600 dpi와 SVG 다운로드, 편집 작업 JSON 저장/열기, 되돌리기
- 국가별 자동 화살표·범위 타원, 기호 위치 이동 시 연결 유지
- 국경선·해안선 개별 굵기, 바다 회색 농도, 기호 흰색 외곽선
- 전체 및 개별 기호 크기 12~80(0.5 간격), 설치된 KoPub돋움체 기본 사용
- 지도 중심 위도를 기준으로 자동 계산하는 거리 축척 막대

KoPub돋움체는 이 기기에 설치된 `KoPubDotum Medium`을 이용합니다. 다른 기기에서 같은 글꼴로 보려면 해당 글꼴이 설치되어 있어야 합니다. PNG는 저장 당시 모양을 유지하며 SVG는 글꼴 설치 상태에 영향을 받습니다. 폰트 파일은 사이트에 포함하지 않습니다.

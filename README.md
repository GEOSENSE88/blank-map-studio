# 백지도 스튜디오

제작 · 산남고 이성훈

세계지리 출제용 백지도 편집기. `dist/index.html`을 브라우저로 바로 열거나, `dist` 폴더를 정적 웹 서버로 제공하면 실행됩니다. 외부 서비스 요청 없이 동봉한 지도 자료를 이용합니다.

지도 자료는 `dist/data/mapdata.js`에 담아 `<script>`로 읽습니다. `fetch`를 쓰지 않으므로 파일을 두 번 눌러 여는 `file://` 환경에서도 지도가 정상적으로 뜹니다. `dist/data/*.json`은 같은 자료의 원본이며 `mapdata.js`가 없을 때만 예비로 쓰입니다.

한국지리 자료는 `dist/data/koreadata.js`(시도·시군구 TopoJSON)에 들어 있습니다.

## 주요 기능

- 지도 종류 전환 · 세계지리 백지도와 한국지리 백지도
- 한국지리는 권역별(6) · 시도별(17) · 시군별(161 · 일반구와 광역시 자치구는 부모 시·광역시로 통합) 단위와 전국·수도권·강원권·충청권·호남권·영남권·제주권 범위
- 축척 막대(지도 범위에 따라 25·50·100km 등으로 자동)
- 바다·해양 이름 24종을 제자리에 넣기(대양은 한 번에 넣기 가능, 기호보다 작게 표시)

- 지역·중심 경선 선택, 확대·이동
- 지도 미리보기 오른쪽·아래·모서리 손잡이를 끌어 크기를 바꿉니다(mm 직접 입력·빠른 크기 프리셋도 가능, 30~300mm)
- 기호·지점·위선 눈금 크기가 인쇄 크기 기준으로 자동 맞춤 — 지도를 키우든 줄이든 종이 위 글자 크기는 일정합니다(세계지리 3.9mm · 시군 3.2mm · 시도 3.6mm, 끄고 직접 지정 가능)
- 도법 선택 · 로빈슨(기본)·밀러·몰바이데·에케르트 4·빙켈 3·정거방위·메르카토르·정거원통
- 국가별 음영·빗금과 자동/직접 기호, 드래그로 기호 이동
- 위선 눈금과 라벨은 그림 테두리에 고정됩니다
- 바다 이름 같은 T 기호 글자는 흰색 외곽선 없이 표시하며, 선택 후 개별로 켜고 끌 수 있습니다
- 지점(도시·위치를 검은 점과 기호로 표시), 연결선, 강조 타원, 명조·고딕, 국경선·경위선과 적도 0°·남북위 30°·60° 위선 눈금
- PNG 300/600 dpi와 SVG 다운로드, 되돌리기
- PNG은 지정한 인쇄 해상도로 곱바로 그려 저장하므로 선이 번지지 않습니다
- 기호를 국가 안쪽에 우선 배치하고, 들어가지 않는 작은 국가만 화살표로 연결
- 국경선·해안선 개별 굵기, 바다 회색 농도, 기호 흰색 외곽선
- 전체 및 개별 기호 크기 12~80(0.5 간격), 설치된 KoPub돋움체 기본 사용
- 국가 음영과 지점이 한 줄기로 이어져 A, B, C… 순으로 붙고, 위쪽부터 왼→우로 자동 정렬됩니다
- 지점을 연속으로 찍으면 기호가 다음 글자로 자동으로 넘어가며, 기호가 붙는 방향은 8방향으로 고를 수 있습니다
- 기호를 밖으로 끌어내면 화살표가 자동으로 생기며, 타원은 선택했을 때에만 표시

KoPub돋움체는 이 기기에 설치된 `KoPubDotum Medium`을 이용합니다. 다른 기기에서 같은 글꼴로 보려면 해당 글꼴이 설치되어 있어야 합니다. PNG는 저장 당시 모양을 유지하며 SVG는 글꼴 설치 상태에 영향을 받습니다. 폰트 파일은 사이트에 포함하지 않습니다.

## 작업 저장

[저장] / [열기]는 브라우저(`localStorage`)에 이름을 붙여 보관합니다. 최대 30개를 가지며 같은 이름으로 저장하면 덮어씁니다. 다른 기기로 옮길 때만 ‘파일로 내보내기 / 파일에서 가져오기’를 쓰세요.

## 이용자 수 카운터

기본값은 **이 기기의 이용 횟수**를 `localStorage` 에 세어 보여 줍니다. 외부로 요청을 보내지 않고 오프라인에서도 동작합니다.

사이트 전체 누적 이용자를 세려면 `dist/app.js` 의 `VISIT_API` 상수에 카운터 API 주소를 적으세요. 응답의 `count` / `value` / `data.up_count` 중 숫자가 있는 값을 읽으며, 실패하면 기기 기준 집계로 돌아갑니다. 이 경우에만 외부 요청이 발생합니다.
